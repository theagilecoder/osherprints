# Osher

Osher turns a child's photo into a personalized 3D-printed character figure,
optionally hand-painted, ordered via WhatsApp.

V1 is a static single-page site for parents in India. No backend, no build
step. See `AGENTS.md` for commands and conventions.

## Commands

- Preview: `python3 -m http.server 8000` then open http://localhost:8000
